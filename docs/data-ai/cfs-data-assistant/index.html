OVERVIEW

문서 개요

이 기록의 배경은 물류 센터입니다. 상품을 받아 보관하고, 주문이 들어오면 창고에서 물건을 집어(피킹) 포장해 내보내는 곳입니다. 이 과정이 모두 데이터로 남기 때문에, 운영 담당자의 일은 물건을 옮기는 것보다 그 데이터를 읽고 이상을 찾아내는 쪽에 가깝습니다.

그런데 실제로 요청이 들어오는 형태는 늘 애매합니다. "에러 났고 유통기한도 빈 건만 골라서 불량률 뽑아 주세요"처럼 조건이 여러 개 겹치거나, 데이터베이스에 직접 물어봐야 하는데 개발자를 기다릴 수 없거나, 새벽에 사고가 났는데 보고 받을 사람이 외국인 임원인 경우입니다.

이 문서는 그 세 가지를 AI를 도구로 써서 직접 해결한 과정을 그대로 재현해 둔 기록입니다. 순서대로 ① 조건이 겹친 엑셀 집계, ② 개발자 없이 DB에서 데이터 뽑기(SQL), ③ 한국어 현장 보고를 영문 임원 보고로 변환이며, 각 단계의 버튼을 누르면 실제로 어떤 수식·쿼리·문장이 나왔는지 볼 수 있습니다. 등장하는 수치와 이름은 설명을 위해 재구성한 예시입니다.

도전 2. 개발자 없이 복잡한 DB 데이터 추출 (SQL)

목표: 일상적인 비즈니스 언어로 된 요청을 해석하여 완벽한 SQL JOIN 쿼리로 변환 및 실행

Situation: 매니저의 긴급 데이터 추출 요청
"재석님, 이번 주 출고 지연된 건 중에서 서울 센터 물량만 센터명과 상품아이디 포함해서 리스트 뽑아주세요!"

- Orders Table: id, item_id, center_code, status
- Centers Table: center_code, center_name, region
👇 클릭 한 번으로 쿼리 생성
🔒 AI를 통해
DB를 조회하세요
After: 쿼리 생성 결과
▶ 도출된 쿼리문:
SELECT o.id, o.item_id, c.center_name 
FROM Orders o
JOIN Centers c ON o.center_code = c.center_code
WHERE o.status = 'Delayed' 
  AND o.center_code = 'SEL';
