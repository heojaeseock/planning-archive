전략 1의 파이프라인은 10,000건에서 3,500건을 걸러냅니다. 이 수치가 무엇을 뜻하는지, 함께 제시한 시간 절감과 어떤 관계인지 정리했습니다.

1차 · 볼 것이 줄어듭니다

기계가 걸러낸 3,500건만큼 평가 대상이 줄어듭니다. 계산이 쉬운 직접 효과입니다.

2차 · 남은 판정의 품질이 오릅니다

작업 시간이 짧아져 정확도가 급락하는 후반 구간에 닿기 전에 끝납니다. 같은 사람이 같은 데이터를 봐도 결과가 달라집니다.

이 2차 효과가 제안의 핵심입니다. 단순 반복을 걷어내는 것은 시간을 아끼는 일이면서 동시에 품질을 올리는 일입니다.

두 수치는 같은 대상을 잰 값이 아닙니다

35% 제거는 전체 데이터 물량 기준이고, 75% 시간 절감은 단순 반복 작업에 쓰던 시간 기준입니다. 전체 시간을 물량에 비례한다고 보면 40시간 × 0.65 = 26시간입니다.

그래서 보고할 때 두 수치의 대상을 함께 적습니다. 구분 없이 내놓으면 35% 걸러서 75% 줄었다는 말이 되어 근거를 되묻게 됩니다.

리스크

3. 규칙 기반 필터가 지워버릴 수 있는 것

정상 데이터가 규칙에 걸리는 경우가 있고, 그 손실은 눈에 보이지 않습니다.

가장 위험한 경우

금칙어 필터가 안전성 학습 데이터를 지웁니다

이 표현이 왜 문제가 되나요, 이런 요청은 거절해야 하나요 같은 질문에는 금칙어가 들어갈 수밖에 없습니다. 그런데 이런 데이터가 바로 AI에게 무엇을 거절해야 하는지 가르치는 자료입니다. 자동 대조로 반려하면 가장 학습해야 할 영역이 평가자 눈에 닿기도 전에 사라지고, 제거된 사실은 로그에만 남습니다.

글자 수 초과 규칙

상세한 설명을 요구하는 질문에는 긴 답변이 정답입니다. 길이만으로 자르면 고품질 장문이 함께 빠집니다.

자음 반복 규칙

감정 표현이나 구어체 데이터에서는 ㅋㅋㅋ가 유효한 입력입니다. 대화형 모델에는 오히려 필요한 표본입니다.

그래서 제거가 아니라 분류로 바꿉니다

삭제하지 않고 별도 큐로

규칙 위반 후보 큐로 분리합니다. 주 작업 흐름에서는 빠지므로 효율은 그대로 얻고 데이터는 남습니다.

오제거율을 잽니다

분리된 큐에서 표본을 뽑아 사람이 확인합니다. 정상 데이터가 섞인 비율이 규칙을 조정하는 근거가 됩니다.

안전 관련은 규칙에서 뺍니다

금칙어가 소재인지 공격인지는 규칙으로 못 가릅니다. 자동 반려가 아니라 우선 검토 표시로만 씁니다.

이렇게 바꾸면 확실한 제거는 형식 검증 2,000건, 35%가 아니라 20%가 됩니다. 낮춰 보고하는 편이 안전합니다. 나중에 오제거가 드러나면 효율 수치 전체가 신뢰를 잃기 때문입니다.

1단계가 2단계를 막고 있었습니다

2단계 질문 의도 파악은 표현이 아니라 목적을 보라는 지침입니다. 그런데 1단계에서 키워드만 보고 즉시 반려하면 의도를 볼 기회 자체가 없어집니다. 강남역 대박 맛집처럼 표현은 거칠어도 의도가 정상인 경우가 훨씬 넓습니다.

지금 순서

키워드 확인 → 즉시 반려

바꾼 순서

키워드 확인 → 위반 후보 → 의도 파악 → 판정

아동 관련 불법 소재처럼 의도와 무관하게 금지되는 항목은 1단계에서 끝냅니다. 단계를 가르는 기준은 명백함이 아니라 의도가 판정을 바꿀 수 있는지입니다.

3단계는 그대로 둡니다

판단이 서지 않는 사례를 감으로 넘기지 않고 기록으로 쌓는 설계입니다. 기준의 일관성은 지침 문서의 완성도가 아니라 예외 사례가 쌓이는 속도로 정해집니다. 여기에 평가자 간 일치도 측정을 붙여, 기록이 실제로 일관성을 높이는지 확인합니다.

4. 측정할 지표

측정할 지표

  • • 오제거율: 필터에 걸린 데이터 표본 중 실제 정상 데이터의 비율 — 3번 보완의 핵심 지표
  • • 평가자 간 일치도: 같은 데이터를 두 명 이상이 평가했을 때 판정이 같은 비율 — 전략 2의 실효를 보는 유일한 방법
  • • 시간대별 정확도 실측: 1번의 곡선은 예상 추이이므로, 정답이 확인된 표본을 시간대별로 배치해 실제 하락 여부를 측정합니다
  • • 건당 처리 시간: 필터 도입 전후, 그리고 시간대별 변화
  • • 예외 사례 축적 속도: 가이드라인에 새로 등재된 사례 수와, 등재 이후 같은 유형의 재문의 감소
