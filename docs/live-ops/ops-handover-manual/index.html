🕒 1. 업데이트 전 준비

  • 매 업데이트 빌드노트 확인 CDN 때도 수정할 게 가끔 있지만, 보통 월 말 대규모 빌드 업데이트 시 수정 사항이 많습니다.
  • 가이드 수정/추가 내용 찾기 (선별 작업) 빌드 노트 확인 후 기존 가이드 수정이 필요하거나 신규로 추가가 필요한 내용을 직접 판단하여 선별합니다.
    ⭕ 가이드 제작/수정 필요
    • 신규 콘텐츠: 홍문록, 역왕무공 등
    • 기존 내용 수정: 수호령 초월 추가, 등급 추가, 신규 직업, 던전 추가 등
    ❌ 가이드 제작 필요 없음
    • 기존 누락분: 예전부터 있던 콘텐츠인데 기존 가이드 내에 없는 것
    • 단기 이벤트성: 경공전, 백몽 키우기 등 단기간 진행되는 콘텐츠

    💡 내용 판단이 애매할 경우: 민수님, 인선님, 재석님에게 문의하여 결정합니다.

    💡 작성 꿀팁: 빌드노트 내 비슷한 내용을 라이브 가이드에 검색해 보고, 해당 포맷을 활용하여 수정하는 것을 추천합니다.

  • 가이드 수정 스케줄 시트 탭 생성 시트 하단에 새로운 수정내역, 수정 목록 시트를 생성합니다.
    (ex. 260226_수정내역, 260226_수정목록)
  • 수정 내역 시트 작성 빌드노트에서 확인한 수정 필요 내역을 빌드 노트 원문 그대로 복사/붙여넣기 합니다.
  • 수정 목록 시트 작성 수정 내역 시트에 있는 내용을 바탕으로 가이드 제목 > 작업 내용(빌드노트 내용) > 가이드 수정 사항(가이드에 반영할 내용) 순서로 가공하여 작성합니다.

🛠️ 2. 가이드 수정

⚠️ 중요 사항 가이드 수정은 특별한 상황이 아니면 반드시 데브(Dev) 환경에서 먼저 수정하여 라이브(Live)로 이관하는 것을 원칙으로 합니다.

🚀 3. 업데이트 당일 (이관)

  • 가이드 이관 진행 업데이트가 시작/완료된 이후, dev 환경에서 작업해 둔 가이드를 라이브(Live) 환경으로 이관합니다.
  • 정상 이관 확인 실제 라이브 가이드 웹페이지에 접속하여 수정/추가된 내용이 깨짐 없이 정상적으로 적용되었는지 최종 확인합니다.

🔄 4. 서버 이전 관련 작업

※ 서버 이전 시마다 별도의 가이드 수정이 필요합니다.

  • 가이드 내용 갱신 이전 서버 이전 가이드를 참고하고, 공식 포럼에 올라온 최신 서버 이전 공지를 확인하여 변동된 조건 및 일정을 수정합니다.
  • 크로스 체크 진행 작성된 내용에 오류가 없는지 팀원들에게 공유하여 더블 체크(Cross-check)를 진행합니다.
