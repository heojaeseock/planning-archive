Game System Analysis Report

브롤스타즈
시스템 구조 및 모델 분석

글로벌 모바일 슈팅 게임 '브롤스타즈'의 장기 흥행 요인을 분석했습니다.
핵심 재화 순환, 브롤 패스 기반 과금 모델, 브롤러 성장 체계와 요구 재화, 플레이 모드까지 게임의 뼈대를 도식화했습니다.
그 위에서 확인한 내용을 정리했습니다.

🏆 Supercell

분석 범위

출시 이후 장기간 상위 매출을 유지하는 요인을 재화 순환, 성장 단계, 플레이 모드로 나눠 도식화했습니다.
확률형 뽑기 대신 패스제와 외형 상품으로 과금 축을 옮긴 설계가 분석의 중심입니다.

핵심 재화 및 과금 모델 분석

🚀 레벨업에 따른 점진적 스킬 해금 구조

Level 7

가젯

브롤러 고유의 액티브 특수 스킬로, 게임당 사용 횟수가 정해져 있습니다.
하단의 초록색 버튼을 눌러 사용합니다.

Level 8 & 10

기어

공통/영웅/신화로 나뉘는 패시브 능력으로, 8레벨과 10레벨에 슬롯이 하나씩 열립니다.

Level 9

스타 파워

브롤러에게 강력한 핵심 패시브 능력을 부여하거나 기존 능력을 진화시키는 시스템.

Level 11

하이퍼차지

버프형 궁극 액티브 스킬입니다.
특수 공격과 같이 충전식이며, 일시적으로 능력치를 올리고 특수 공격을 크게 강화합니다.

Core Insight & Conclusion

"직관적인 전투와 합리적인 패스제 BM으로 유저 진입 장벽은 낮추고,
