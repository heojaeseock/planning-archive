현황과 제안 범위

커뮤니티 불만 글을 유형별로 분류한 결과, 서버 튕김과 입장 렉이 41%로 가장 큰 비중을 차지했습니다.
의도와 무관한 이탈이 탈주로 처리되는 데다, 랭크전 전용 보상이 없어 상위 티어 달성 이후의 플레이 동기도 약합니다.
기술적 결함 보완과 성취 노출·보상 장치를 합쳐 리플레이, POTG, 사후 채팅, 맵 밴, 티어 보상 5종을 제안했습니다.

# 현황 및 주요 페인포인트

🚨 기술적 결함으로 인한 이탈

커뮤니티 불만 글을 유형별로 직접 분류해 보니 서버 튕김 및 입장 렉(41%)이 가장 큰 비중을 차지했습니다.
이는 유저의 의도와 상관없는 탈주 처리를 유발해 강한 부정적 경험을 줍니다.

⚔️ 빠른 템포의 경쟁력 활용

서든어택의 강점인 짧은 플레이 타임과 직관성을 보조할 수 있는 시스템이 필요합니다.
불필요한 마찰을 줄이고 게임 몰입도를 높이는 방향이 핵심입니다.

🎁 지속적 동기 부여 장치 부재

랭크전 전용 희소성 있는 보상 체계가 부족하여, 상위 티어 달성 후 유저들이 플레이를 지속해야 할 명분이 부족한 상태입니다.

정합성 점검 및 우선순위

제안을 나열한 뒤에는 “내가 정의한 문제를 실제로 덮고 있는가”를 되짚어야 합니다. 1번 탭의 불만 분포와 2번 탭의 제안 다섯 건을 맞대어 보면 비어 있는 칸이 드러납니다.

점검 결과

1번 탭은 스스로 “기술적 결함 방어가 최우선 과제”라고 결론냈고, 그 비중은 41%로 1위입니다. 그런데 제안 다섯 건 중 이 항목을 다루는 제안이 하나도 없습니다.
제안들은 13%(핵), 15%(보이스톡), 그리고 성취 동기 쪽에 몰려 있습니다. 가장 큰 문제를 정의해 놓고 대응은 나머지에 배치한 상태입니다.

#

2. 빈 칸을 메우는 제안 — 기획으로 할 수 있는 것

서버 안정화 자체는 인프라·개발 영역이라 기획서가 약속할 수 없습니다. 그러나 “튕김이 탈주로 처리되는 것”은 판정 로직의 문제이므로 기획 영역입니다. 41%의 불만이 강한 이유는 렉 자체보다 억울한 페널티에 있습니다.

신규 제안 A 재접속 허용

비정상 종료 시 일정 시간 해당 슬롯을 비워 두고 복귀를 허용합니다. 복귀에 성공하면 탈주 판정을 취소합니다. 팀은 인원 공백을 견디는 대신 경기 자체가 무산되지 않습니다.

신규 제안 B 비정상 종료와 고의 탈주 분리 판정

종료 직전 패킷 유실 · 응답 지연 · 클라이언트 크래시 로그를 근거로 두 경우를 나눕니다. 기술적 원인으로 판정되면 페널티를 면제하고, 반복 패턴은 별도 누적 관리합니다.

신규 제안 C 입장 실패 시 매칭 자동 복구

입장 단계에서 실패한 경우 경기를 성립시키지 않고 큐로 되돌립니다. ‘시작도 못 했는데 패배’가 가장 큰 불만 유형이므로, 성립 조건을 뒤로 미루는 것만으로 상당 부분이 해소됩니다.

세 제안 모두 서버 성능을 개선하지 않고도 불만의 원인인 ‘억울한 손실’을 제거합니다. 근본 해결(인프라 개선)과 병행할 수 있는 완충 장치입니다.

#

3. 기존 제안에서 다시 봐야 할 두 건

재검토 Proposal 03 · 사후 채팅

사망한 유저가 아군에게 브리핑을 보내는 구조는, 경쟁 FPS에서 통상 금지하는 관전 정보 전달(고스팅)에 해당합니다. 사망자는 관전 시점에서 생존자가 볼 수 없는 적 위치를 볼 수 있기 때문입니다.

원안의 제한이 충분하지 않은 이유

원안은 ‘생존자는 팀원의 사후 채팅만 수신’으로 악용을 막으려 했습니다. 그런데 막아야 하는 것은 적 팀의 열람이 아니라 사망자가 관전으로 얻은 정보가 생존자에게 흐르는 것입니다. 제한의 방향이 어긋나 있습니다.

대안: 기획 사유가 ‘보이스톡 오류 보완’이었으므로, 목표를 생존자 간 텍스트 소통 강화로 되돌리는 편이 정합적입니다. 라디오 메시지(정형 문구) 단축키, 핑(위치 표시) 시스템처럼 관전 정보가 섞이지 않는 수단이 같은 문제를 부작용 없이 해결합니다. 사후 채팅을 유지하려면 사망자의 관전 시점을 제한하는 설계가 선행되어야 합니다.

재검토 Proposal 05 · 티어 보상에 유료 캐시 포함

최상위 티어에 유료 캐시를 직접 지급하는 설계는 두 가지를 동시에 불러옵니다.

매출 잠식

상위 티어 유저는 원래 결제력이 높은 층입니다. 이들에게 캐시를 지급하면 그만큼의 결제가 사라집니다.

어뷰징 유인

보상이 현금성이면 대리 랭크 · 승부 조작 · 부계정 팀 매칭의 기대 수익이 생깁니다. 랭크의 신뢰도 자체가 위협받습니다.

대안: 동기 부여의 핵심은 금액이 아니라 희소성과 가시성입니다. 시즌 한정 칭호 · 무기 스킨 · 프로필 배경처럼 거래도 환금도 되지 않는 외형 보상이 같은 명예욕을 자극하면서 매출 잠식과 어뷰징 유인을 만들지 않습니다. Proposal 02(POTG)와 결합해 ‘보이는 성취’로 묶으면 효과가 더 커집니다.

4. 실행 우선순위

1순위 신규 A·B·C (재접속 · 분리 판정 · 입장 복구) 불만 41% 직접 대응
2순위 Proposal 01 리플레이 13% 대응 + 신고 정확도 향상
3순위 Proposal 02 POTG + 05(외형 보상으로 수정) 성취 노출 묶음 처리
4순위 Proposal 04 맵 밴 매칭 시간 증가 · 맵 편중 심화 감시 필요
보류 Proposal 03 사후 채팅 고스팅 검토 후 대안(핑·라디오)으로 대체

검증 지표

  • • 재접속: 비정상 종료 중 복귀 성공률, 탈주 페널티 부과 건수 변화
  • • 분리 판정: 페널티 이의 제기 CS 인입 건수 (감소가 목표)
  • • 입장 복구: 입장 실패로 성립된 경기 비율
  • • 리플레이: 신고 처리율과 제재 확정률
  • • 맵 밴: 평균 매칭 대기 시간, 맵별 선택 편중도

이 점검의 한계

  • • 41% 등 비중은 커뮤니티 게시글을 직접 분류한 자체 취합 값이며 공식 통계가 아닙니다. 표본이 불만 표출 유저에 편중돼 있습니다.
  • • 재접속·분리 판정은 클라이언트 로그 수집 범위에 따라 구현 가능성이 달라집니다.
  • • 매출 잠식 규모는 결제 데이터 없이 추정하지 않았습니다. 방향만 제시했습니다.
  • • 개발 공수는 산정하지 않았습니다. 우선순위는 문제 비중과 리스크 기준입니다.

정리

제안을 늘리는 것보다 정의한 문제를 실제로 덮었는지 확인하는 일이 먼저입니다.
점검 결과 가장 큰 문제(41%)가 비어 있었고, 제안 두 건은 부작용을 안고 있었습니다.

빈 칸을 메웠습니다

서버 성능은 기획 영역이 아니지만 탈주 판정 로직은 기획 영역입니다. 재접속·분리 판정·입장 복구로 ‘억울한 손실’을 제거합니다.

부작용을 걸러냈습니다

사후 채팅은 고스팅, 캐시 보상은 매출 잠식과 대리 유인을 만듭니다. 핑·라디오와 외형 보상으로 대체했습니다.

순서를 문제 비중에 맞췄습니다

기존 제안은 13%·15% 문제에 몰려 있었습니다. 41%를 1순위로 올리고 나머지를 뒤로 재배치했습니다.
