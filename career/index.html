프로젝트 요약

  • 반복적인 기획서(CSV) 데이터를 포럼 공지사항용 HTML 소스로 자동 변환하는 사내망 웹 도구를 단독 기획·제작
  • 미공개 업데이트 데이터가 외부로 나가지 않도록, 기획서 파일은 서버에 올리지 않고 브라우저 안에서만 읽는 구조로 설계
  • 도구 자체는 외부망과 분리된 사내망에 배포하고, 밖으로 나가는 통신은 사내 AI 호출 하나로 제한
  • 해외 공지는 내장 용어 사전으로 번역하고 사전에 없는 단어만 사내 AI로 채우게 해, 번역 편차와 외부 전송을 함께 축소
  • AI를 부를 때는 상품명·가격·날짜를 지어낸 값으로 바꿔서만 내보내고, 전송 전 확인 창과 값이 남지 않는 호출 기록을 함께 설계
  • 상점 이름, 판매 기간, 대상 서버를 UI에서 설정하면 원클릭으로 소스가 나오고, 게시 전 점검과 회수 아이템 자동 감지까지 한 화면에서 처리
  • Gemini로 초안을 생성한 뒤 Claude Code로 코드 구조와 예외 처리를 다시 잡는 방식으로 고도화

🏆 핵심 성과

  • 기획서 데이터를 하나씩 표로 옮기던 수동 작업을 원클릭 HTML 생성으로 대체해 공지 작성 시간을 크게 줄이고 오타·데이터 누락을 차단
  • 기획서 파일을 서버에 올리지 않고 처리하는 방식으로 사내 정보보호정책팀·AI지원팀 보안 검토를 통과하고 실제 운영 툴로 승인받아 도입
  • 국내 공지 전용이던 도구를 영어·중국어 번체·태국어·일본어 4개 권역 공지까지 처리하도록 확장
  • 담당 서비스에 맞춰 두었던 변환 규칙을 게임 선택 방식으로 분리해 전사로 확산하고, 현재 다른 프로젝트에서도 실제 운영에 사용 중
  • 무료·1원 상품과 판매 중지 항목은 자동으로 빼고 게임 재화 상품은 남기는 등, 실무에서 매번 걸리던 예외를 규칙으로 정리
